01

Question & approach

The question

How can non-technical music learners adjust pitch and speed independently while keeping their original audio safe?

The approach

FFmpeg/FFprobe and Rubber Band handle audio inspection, pitch, and tempo processing. I run that work in the background and treat cancellation, filename conflicts, and partial outputs as normal paths the app must handle. Source files stay unchanged, and output creation is exclusive to avoid overwriting an existing file.

02

My contributions

  1. 01

    Independent development on two platforms

    I independently developed the original Windows application and the Apple Silicon macOS version. In August 2026, I delivered the tested, packaged macOS pre-release within 3 days.

  2. 02

    Independent learning controls

    I implemented independently configurable pitch changes from -24 to +24 semitones and speed changes from -95% to +400%, with MP3, M4A, WAV, and FLAC inputs.

  3. 03

    Cancellation with cleanup

    I added background processing, child-process-group cleanup, exclusive non-overwriting output creation, source-file protection, and partial-file removal on failures or cancellation.

  4. 04

    Tests that challenge failure behavior

    I covered validation, filesystem conflicts, fault injection, real processing, packaged execution, cancellation, cleanup, source protection, and GUI behavior.

  5. 05

    A distributable release

    I bundled Python and audio tools, audited native binaries and library references, validated on a separate non-development Mac, and prepared licensing, corresponding source, checksums, and a public pre-release.

03

How the app behaves in use

  1. 01

    Choose pitch and practice speed independently

    Set -24 to +24 semitones and -95% to +400% speed change for MP3, M4A, WAV, or FLAC input.

  2. 02

    Process in the background

    The interface remains responsive while FFmpeg and Rubber Band perform the audio work.

  3. 03

    Resolve output conflicts without overwriting

    Existing files retain their contents; numbered suffixes allocate a new output, with exclusive creation protecting against conflicts.

  4. 04

    Cancel and clean up

    Cancellation terminates the related process group and removes partial output. Release checks observed the source file unchanged and no leftover partial files.
