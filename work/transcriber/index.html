Question & approach

The question

How can students follow live lectures using on-device transcription without a cloud transcription service or a preconfigured development environment?

The approach

The app runs Whisper locally through whisper.cpp and Metal. Overlapping audio chunks keep capture continuous, but can repeat words at chunk boundaries. I preserve the original output before applying conservative cleanup, then save both versions with the session log and configuration. Capture and inference run in asynchronous workers so the UI can remain responsive.

02

My contributions

  1. 01

    A local audio pipeline

    I built asynchronous capture and inference workers to keep the interface responsive while audio is processed. Microphone audio is buffered and resampled from 48 kHz to the 16 kHz format used by Whisper.

  2. 02

    Model downloads and management

    I added model scanning, import, selection, and managed downloads with exact-size and SHA-256 checks, temporary staging, retry handling, and atomic publication.

  3. 03

    Original transcripts and clean text

    I save raw backend output before boundary-overlap deduplication. Users can compare the clean transcript with the original, while the model, language, logs, and session configuration remain available for inspection.

  4. 04

    Packaging and release engineering

    I packaged Python and native libraries into a standalone macOS app, pinned build dependencies, and tested inference in the packaged application.

03

How the app behaves in use

  1. 01

    Load a verified model

    Downloads remain temporary until exact-size and SHA-256 checks pass. Users can also import a local model.

  2. 02

    Transcribe while keeping the UI responsive

    Audio capture and local inference run asynchronously. Overlapping chunks feed the Metal-enabled backend.

  3. 03

    Keep the original beside the cleaned text

    Each session saves raw.txt and clean.txt plus session.log and config.json, so cleaned output can be checked against what the backend produced.

  4. 04

    Continue working with saved sessions

    Incremental copying, safe renaming, and full-history recovery operate on the retained session outputs.
